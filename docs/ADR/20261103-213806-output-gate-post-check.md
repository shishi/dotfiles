# 最終回答を表示前に検査する

- 状態: 採用
- 日付: 2026-11-03

## 背景

指示をモデルに渡すだけでは、未確認の主張や依頼の抜けを表示前に検出できません。不可逆な操作には実行前のガードが必要です。

## 決定

最終回答を別のモデルで検査し、未達があれば同じセッションで作業を続けさせます。検査に失敗した場合は、確認が未完了であることと原文を表示します。危険な操作の実行前ガードは併用します。

検査には依頼、会話、回答、ツールの呼び出しと結果、応答規則を使います。送信前に秘密情報を検出して伏せます。規則は、回答の訂正か作業の続行で解消できる違反を対象にします。

## 選択肢

| 方式 | 判断 |
|---|---|
| 事前に指示するだけ | 表示前に未達を検出できません |
| 未達を添えて表示する | 未達を解消していない回答が届きます |
| 未達を返して続行する | 未達の解消を試みられます |
| 実行前ガードだけを使う | 操作は判定できますが、回答の内容は判定できません |

## 影響

- 回答ごとに検査の時間とモデルの利用枠が必要です。
- 誤判定は不要な差し戻しを、見落としは未達の回答の表示を招きます。
- 回答後の検査では、実行済みの操作を取り消せません。
- 対応する hook や中継を利用できない経路では、表示前の保留や続行を保証できません。

## 確認

`tests/output-gate-check.py` は検査結果の処理を、`tests/output-gate-rules-live.py` は実際の検査役の判定を確認します。構成、利用方法、制約は [出力ゲート](../output-gate.md) を参照してください。
