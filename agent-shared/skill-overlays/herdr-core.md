## このリポジトリでの補足

この節より後ろは、インストールされている hc が `hc --skill` で出力する手引きです。次の 2 点は手引きより優先します。

- 子が `blocked` を報告したら、画面を読んで質問と権限確認を見分けます。委任した作業の範囲内の質問は、選択肢を確かめて `hc keys` で答えます。権限確認は対象の操作を照合し、不足する承認を利用者から取得します。
- Codex のモデルは手引きの例のように版番号で指定せず、起動のたびに `"$HOME/.agent-shared/bin/codex-model" <系統>` で最新の名前を解決して渡します。
