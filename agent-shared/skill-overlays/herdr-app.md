## このリポジトリでの補足

表示も依頼の成果に含まれる場合は、手引きの `herdr-app ls` と `status` で、表示先と対象を確かめます。たとえば差分の表示は `hunk-review` に従います。子の作業を親が観測するだけなら Core の端末を読み、画面を移動する必要があるときは、操作前に対象のタブやペインを特定します。Core の端末 ID を App のペイン ID として使いません。
