# エージェントへの作業割当

共通 AGENTS.md の事前送信承認・権限境界・司令塔の責任を引き継ぎます。担当選択と起動前の確認を行い、成果と直接の検証結果を回収します。短い操作は親が直接処理することを第一候補にします。

## 起動前に読む参照

現在の担当と実行方式に対応する本文を、起動前に読みます。同版を既読なら再利用し、不要な方式の参照は読みません。

| 場面 | 必須の参照 |
|---|---|
| 委譲・レビュー・受入・長いバックグラウンド実行の割当、観測、待機直前の判断 | [作業の割当・観測・利用枠と履歴](references/execution.md) |
| Codex 内の子を起動 | [Codex の子とモデル選択](references/codex-children.md) |
| Claude 内の子、または最上位の Claude から Codex への委譲を選択 | [Claude Code の委譲とモデル選択](references/claude-children.md) |
| 別 CLI を一般作業・レビュー・対話で起動 | [認証方式と送信先の確認](references/authentication.md) |
| モデルが利用不能、または代替候補を決める | [モデル代替](references/model-fallback.md) |

役割だけでモデルを固定せず、担当する仕事の曖昧さ・影響範囲・検証の容易さから選びます。別 CLI で受託中の場合は、同じツール内の子にも受託範囲と別 CLI への再委譲禁止を引き継ぎます。

## 実行用 skill へ渡す

- Codex から Claude への一般作業は `claude-delegate`、Claude から Codex へは `codex-delegate` を使います。この skill は各 adapter のコマンド・権限設定を複製しません。
- 独立レビューは `review-gate` と `claude-review` / `codex-review` へ渡します。レビューの編成・順序・採否は `review-gate` を正本とし、受託側で追加の独立レビューを重ねません。
- 起動前に担当範囲・入力・維持条件・受入条件・権限・締切・進捗の観測点を確定します。CLI の接続先確認と秘密情報検査を終えてから、既存の承認範囲に合う実行へ進みます。
- 受託側から成果物・直接の検証結果・未解決点を受け取り、司令塔が実物と照合して採否・統合を判断します。完了通知だけでは作業完了としません。
