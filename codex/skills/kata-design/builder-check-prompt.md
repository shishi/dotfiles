# builder check の依頼文

設計の記録を書いた後、会話の経緯を知らない新しい agent へ次の依頼文を渡します。`[分野]` と `[記録の場所]` を埋めます。

```
あなたは熟練した [分野 (例: ソフトウェアエンジニア)] です。設計の記録を渡され、
それを実現する計画を立てるよう頼まれました。記録を書いた人には質問できません。

[記録の場所] を読んでください。

計画をうまく立てる前に答えが必要な質問だけを返してください。推測が必要で、
推測を誤ると影響が大きい箇所です。質問ごとに、その答えで計画がどう変わるかを書き、
重要な順に並べてください。

記録が実装者に任せると明示していること、自分で妥当に決められること、
言い回しの指摘は省いてください。

重要な不足が無ければ「重要な不足はありません」と返してください。
```
