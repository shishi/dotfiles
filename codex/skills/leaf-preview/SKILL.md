# Leaf で Markdown をプレビューする

編集対象のファイルを Leaf に渡します。保存を追うライブ表示と、会話へ返すインライン表示を使い分けます。

## 対象と実行環境

- 会話中の編集対象を使います。対象が特定できない場合だけ、どのファイルか確認します。
- `leaf --version` と `leaf --help` で、その環境の実行版と必要なオプションを一度確認します。同じ環境・版での編集ごとに繰り返しません。未導入・起動失敗は `missing-tools` で調べます。
- 既存ファイルを上書きせず、引用した絶対パスを渡します。会話の草稿だけを表示するときは、その内容を作業用 Markdown ファイルへ保存します。正式な文書の保存先と混同しません。

## 編集しながらライブ表示する

利用者が見られる別の端末ペイン・タブ・ウィンドウで、次を実行します。パスは実際の対象へ置き換えます。

```sh
leaf --watch "/absolute/path/to/document.md"
```

1. 利用可能な端末操作ツールと、既に開いているプレビューを確認します。同じ対象のプレビューがあれば再利用します。Herdr など特定の端末の操作を指定された場合は、対応する skill の適用条件と操作手順に従います。
2. 操作できる表示先があれば、そこで起動して初期本文の描画を確認します。非表示の実行セッションや `leaf ... &` だけを、利用者向けのプレビュー画面として扱いません。エージェントのコマンド実行を占有する前景の TUI も避けます。
3. Codex・Claude Code は元の画面で作業を続け、同じ Markdown ファイルへ編集を保存します。変更した本文が Leaf の画面へ反映されたことを確かめます。確認のためだけに利用者の本文を書き換えません。
4. 表示先を操作できない場合は、その制約を伝えてインライン表示を実行します。ライブ表示は未起動と明示し、利用者の別端末で実行できる、対象パスを埋めたコマンドを添えます。

プレビューは依頼された閲覧中は残します。終了を求められたら、自分が起動した Leaf に `q` を送り、終了を確認します。端末全体や別の Leaf プロセスをまとめて終了しません。

## 会話内に表示する

会話での確認や図の提示には、TUI・ブラウザー・別の可視化アプリを使わず標準出力へ描画します。幅は表示先に合わせ、未指定なら 100 を出発点にします。

```sh
leaf --inline plain:100 "/absolute/path/to/document.md"
```

- 実行して得た描画結果を加工せず、そのまま会話へ返します。表・Mermaid 図の桁を保つため、必要なら `text` コードブロックで囲みます。コマンドや元の Markdown だけを返して描画済みとは扱いません。
- 編集後は同じファイルを再描画します。インライン表示は実行時点の結果で、自動更新しません。長い文書は必要な範囲を表示し、抜粋であることを添えます。
- Mermaid は元の `mermaid` コードブロックを含む Markdown を渡します。ASCII 図として描画し、ブラウザーの画像表示と同じ見た目は保証しません。
- 色を扱える端末へ直接出す場合は `--inline ansi:100` を選べます。会話のツール出力では、制御文字を含まない `plain` を使います。

## 呼び出し例

- Codex: `$leaf-preview docs/design.md をプレビューしながら直して`
- Claude Code: `/leaf-preview docs/design.md をプレビューしながら直して`
- 会話内の表示: `この Markdown を Leaf で描画して会話に表示して`

操作の一次資料は [Leaf の公式 README](https://github.com/RivoLink/leaf#usage) です。新しいオプションを使う場合は、実行版のヘルプと照合します。
