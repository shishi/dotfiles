# Hunk でコードや差分を表示する

表示先の指定がなければ、現在のタブを左右に分割 (vsplit) し、Hunk を右側に表示します。その配置で対象を表示中の Hunk があれば、同じペインを使います。

Herdr App では `pane.split` の `right` を使います。表示側の App を端末から操作できず、Core 経由で現在のタブの右端に追加する場合は、作業端末の `herdr.space` と `herdr.tab` を両方引き継いで Hunk を起動します。

ファイルは `hunk open`、作業ツリーの差分は `hunk diff`、コミットは `hunk show` で開きます。パッチファイルには `hunk patch`、GitHub の PR には `hunk gh pr` を使います。

差分を開いたら、説明するファイルや変更箇所に表示位置を合わせます。セッション情報や端末の表示から対象を確認し、どこを開いたか利用者に伝えます。

## ライブセッションの操作

実行中の Hunk に同梱された手順を使います。
`hunk skill show hunk-review` を実行し、出力された手順と制約に従います。
Nix store の絶対パスを保存せず、実行するたびにバイナリから取得します。
手順の取得に失敗したら `missing-tools` で実行版と配備を確認します。
別の古いコピーを代わりに読みません。

同梱手順の対象はライブセッションの CLI 操作です。
起動済みセッション、対象 repo / worktree、利用できる接続経路を確認してから操作します。
個人環境の版別実測は関連記憶を参照し、現在の版の仕様と照合します。
端末の起動・終了には、その端末の操作手順と承認範囲に従います。
