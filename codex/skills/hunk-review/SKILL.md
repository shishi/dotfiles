# Hunk のライブレビュー

実行中の Hunk に同梱された手順を使います。
`hunk skill path hunk-review` の出力するファイルを読み、その版の操作と制約に従います。
Nix store の絶対パスを保存せず、実行するたびにバイナリから解決します。
パスの解決・読込に失敗したら `missing-tools` で実行版と配備を確認します。
別の古いコピーを代わりに読みません。

同梱手順の対象はライブセッションの CLI 操作です。
起動済みセッション、対象 repo / worktree、利用できる接続経路を確認してから操作します。
個人環境の版別実測は関連記憶を参照し、現在の版の仕様と照合します。
この入口はセッションの起動・終了や他の端末の操作権限を追加しません。
