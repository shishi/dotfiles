# Hunk のライブレビュー

実行中の Hunk に同梱された手順を使います。
`hunk skill show hunk-review` を実行し、出力された手順と制約に従います。
Nix store の絶対パスを保存せず、実行するたびにバイナリから取得します。
手順の取得に失敗したら `missing-tools` で実行版と配備を確認します。
別の古いコピーを代わりに読みません。
この入口は実行のたびに Hunk から手順を取得するため、Hunk を更新しても入れ直しは要りません。
Hunk が案内する `npx skills add` は実行しません。同名の skill を導入して、この入口を上書きするためです。

同梱手順の対象はライブセッションの CLI 操作です。
起動済みセッション、対象 repo / worktree、利用できる接続経路を確認してから操作します。
個人環境の版別実測は関連記憶を参照し、現在の版の仕様と照合します。
この入口はセッションの起動・終了や他の端末の操作権限を追加しません。
