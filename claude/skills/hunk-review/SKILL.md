# Hunk のライブレビュー

このファイルは dotfiles で保守する入口です。コードや差分の表示を求められたら、現在のタブの右側に左右分割 (vsplit) で Hunk を表示します。対象を表示中の右ペインがあれば再利用します。利用者が表示先を指定した場合は、その指定に従います。

端末の起動や配置には、その端末の操作手順を使います。Herdr App の画面を操作するときは herdr-app skill を読みます。

表示を求められ、対象のセッションがなければ、表示用の端末で Hunk を起動します。表示側の Herdr App に直接接続できず Core 経由で開く場合は、作業端末の `herdr.space` と `herdr.tab` を両方引き継ぎ、同じタブの右端に追加します。表示後にタブ、左右の配置、対象の差分を確認します。

ファイルは `hunk open`、作業ツリーの差分は `hunk diff`、コミットは `hunk show`、パッチは `hunk patch`、GitHub の PR は `hunk gh pr` で開きます。説明する箇所へ表示位置を合わせ、何を開いたか利用者へ伝えます。

実行中の Hunk に同梱された手順を使います。
`hunk skill show hunk-review` を実行し、出力された手順と制約に従います。
Nix store の絶対パスを保存せず、実行するたびにバイナリから取得します。
手順の取得に失敗したら `missing-tools` で実行版と配備を確認します。
別の古いコピーを代わりに読みません。

同梱手順の対象はライブセッションの CLI 操作です。
起動済みセッション、対象 repo / worktree、利用できる接続経路を確認してから操作します。
個人環境の版別実測は関連記憶を参照し、現在の版の仕様と照合します。
表示の依頼に応じて Hunk を開く場合も、対象の端末と作業場所を確認します。
