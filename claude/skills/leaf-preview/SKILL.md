# Leaf で Markdown を会話に描画する

対象の Markdown を Leaf で描画し、その結果を会話の画面にインラインで返します。別の端末やペインでのライブ表示には使いません。

## 対象と実行環境

- 会話中の対象を使います。対象が特定できない場合だけ、どのファイルか確認します。
- `leaf --version` と `leaf --help` で、その環境の実行版と必要なオプションを一度確認します。同じ環境・版での編集ごとに繰り返しません。未導入・起動失敗は `missing-tools` で調べます。
- 既存ファイルを上書きせず、引用した絶対パスを渡します。会話の草稿だけを表示するときは、その内容を作業用 Markdown ファイルへ保存します。正式な文書の保存先と混同しません。

## 会話内に表示する

TUI・ブラウザー・別の可視化アプリを使わず、標準出力へ描画します。幅は表示先に合わせ、未指定なら 100 を出発点にします。

```sh
leaf --inline plain:100 "/absolute/path/to/document.md"
```

- 実行して得た描画結果を加工せず、そのまま会話へ返します。表・Mermaid 図の桁を保つため、必要なら `text` コードブロックで囲みます。コマンドや元の Markdown だけを返して描画済みとは扱いません。
- 編集後は同じファイルを再描画します。インライン表示は実行時点の結果で、自動更新しません。長い文書は必要な範囲を表示し、抜粋であることを添えます。
- Mermaid は元の `mermaid` コードブロックを含む Markdown を渡します。ASCII 図として描画し、ブラウザーの画像表示と同じ見た目は保証しません。
- 色を扱える端末へ直接出す場合は `--inline ansi:100` を選べます。会話のツール出力では、制御文字を含まない `plain` を使います。

## 呼び出し例

- `docs/design.md を Leaf で描画して見せて`
- `この Mermaid 図を描画して会話に表示して`

操作の一次資料は [Leaf の公式 README](https://github.com/RivoLink/leaf#usage) です。新しいオプションを使う場合は、実行版のヘルプと照合します。
